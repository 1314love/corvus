### D2：tab-id 命名空间不互通 — 已降级为文档化限制

扩展 tab id 与 CDP target id 是不同命名空间，v1.2.0 未做完整桥接。现在工具会返回 typed `BAD_ARGS` 而不是 `INTERNAL`：

- 扩展数字 tab id（例如 `964331934`）经 auto/CDP 工具发送，返回 `BAD_ARGS`，提示 `omit tab_id to use the active tab; extension tab ids are not CDP target ids`。
- CDP 32 位十六进制 target id（例如 `663C5161E60DB696F037243FC631E145`）经扩展工具发送，返回 `BAD_ARGS`，提示 CDP target id 不是扩展 tab id。
- 四个 CDP-only 工具 `browser_console`、`browser_cookies`、`browser_dialog`、`browser_emulate` 收到数字扩展 tab id 时同样返回 `BAD_ARGS`，不再返回 `INTERNAL`。
- active-tab 规避方式通过：省略 `tab_id` 时，`page_snapshot` 与 CDP 工具都操作 active tab。
- 完整 tab-id 桥接延后到 v1.3，作为已记录限制，而不是 v1.2.0 阻塞项。

证据：`evidence/final-explicit/switch.json`、`evidence/final-auto/d2.json`（13/13）。
