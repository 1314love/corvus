The new --allow-no-auth opt-out was verified separately: corvusd serve --bind 0.0.0.0 --allow-no-auth started on 29334/29335, /health returned version 1.4.0 with http_addr 0.0.0.0:29335, and the log contained: WARN corvusd: authentication disabled on public bind bind=0.0.0.0. Known limitation: the auth repository is in-memory. Bootstrap users and refresh tokens do not survive a daemon restart; a pre-restart access token remains valid until its 15-minute expiry because it is a stateless JWT. This is recorded, not treated as a release blocker for 1.4.0.

## 13. Defects, fixes and limitations

Fixed and verified during acceptance:

- **Stale CDP target cache after reconnect (High, task-107).** Fixed by clearing targets, sessions and active_target on disconnect, repairing the active target from current page targets, and mapping stale ids to typed NOT_FOUND. QA reproduced the original kill/relaunch and channel-switch sequence and confirmed no stale ids, no INTERNAL -32602, and working page_snapshot/page_text.
- **Formatting gate on the in-progress task-107 code (Low, process).** Backend2 formatted the two Rust files; the final independent fmt gate is 0.

Recorded limitations:

- The auth store is in-memory: bootstrap accounts and refresh tokens are lost on restart; stateless access JWTs remain valid until expiry. A persistent auth store is not part of 1.4.0.
- Auth is off by default on loopback. Public binds require auth or an explicit --allow-no-auth; the opt-out logs a warning and is not recommended for production.
- Cross-channel tab-id and ref bridging is not implemented; both directions return typed BAD_ARGS. Extension refs are @eN and CDP refs are @cN.
- The extension build's generated contract file still names tests/conformance/schema-snapshot.v1.3.0.json. That snapshot is byte-identical to the new v1.4.0 snapshot (43 tools); conformance itself uses the v1.4.0 snapshot.
- M2b regression used a temporary harness adaptation to the committed fixture; no product code or committed fixture was changed.
- One host, one Chrome for Testing build, and no real external browsers. No live deployment, no Docker/Kubernetes runtime test, and no 72-hour NFR-3 soak were performed.
- The working tree is dirty and uncommitted; the Lead owns the final commit, tag and release. This report is not a release signature.
