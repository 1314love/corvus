### 7.3 High finding and closure

**TASK-162 High finding: intermittent real-CDP worker handshake.**

- Pre-fix frozen worker `f3239d095e9ec26166bb57057669b8b55616d4c5be50b247c8f4adc92e46bb62`: **2/20 PASS** against Chrome 9367; 18 failures in 27–61 ms with `worker_ack ok=false`, code `CDP_ERROR`, message `CDP transport error: connection closed`.
- A fresh pre-fix build `6887c99fe4318fe5c8db27385375bde8d68ca419b59477191a235b66c80eae7b` reproduced the failure (4/5 failures on Chrome 9367).
- Root cause fixed in task-165: a queued stale same-endpoint `SetEndpoint` could close a fresh socket before `Command::Send`; draining controls could drop a pending send. `crates/corvus-cdp/src/client.rs` now ignores same-endpoint reconnects on an active connection, tags sends with ids, rejects pending sends deterministically with `CdpError::NotConnected`, and preserves a queued send while draining controls.
- Regression tests added at `crates/corvus-cdp/src/client.rs:1830,1857,1883,1909,1924`: stale same-endpoint command, duplicate same-endpoint connect, 100 immediate connect/send cycles, send while disconnected without hang, queued send without endpoint rejected rather than dropped.
- Post-fix canonical worker passed 20/20 (420/420) and the fresh target worker passed 20/20 (420/420).

**Limitation:** the pre-fix canonical binary `f3239d09...` was no longer present after the final rebuild, so the final control record is the earlier captured 2/20 test plus the fresh pre-fix build `6887c99...` reproduction above.

## 10. Limitations and observations

1. **No public P1 invoke route.** External clients can complete the encrypted provider handshake and manifest, but cannot trigger `system.info.info` or `tabs.read.list`; those are covered by the real Rust gateway integration test. Accepted scope limitation, not a defect.
2. **Built-extension provider shim gap.** The P1 provider socket is a library module and is not wired into the built extension. This was accepted for P1; no live built-extension-to-Rust-gateway handshake is claimed.
3. **Pre-fix control binary unavailable at final retest.** Canonical pre-fix worker `f3239d09...` was rebuilt away; the earlier 2/20 result and fresh pre-fix build `6887c99...` (4/5 failures) document the failure. Post-fix canonical and fresh workers both passed 20/20.
4. **Daemon version string.** The P1 daemon still reports `version: 1.7.0` in health; this is a product-version observation, not a v2 release claim. The provider handshake manifest is protocol 2 / v2.
5. **Old 1.x/62-tool compatibility not retested.** The v2 direction is a clean-break refactor; the old 62-tool matrix is not a P1 gate.
6. **NFR-3 and live deployment not tested.** No claim is made.
