## 7. Known limits

- No 72-hour NFR-3 soak has been passed, and no live production deployment is claimed.
- No Docker registry image or Kubernetes runtime claim is made; CI validates the image build, health output and manifests.
- Guardrails are a navigation gate, not a network sandbox. Hostnames are not resolved, so DNS rebinding is not detected. `browser_eval`, `page_html` and JSON snapshots can still expose page-controlled content or secrets.
- The policy file path and configuration are visible to the daemon operator; denial details include the policy path.
- Authentication accounts and refresh tokens remain in memory. The REST API is the only authenticated surface.
- Cross-channel tab and reference bridges are not implemented. Acceptance used one host and one Edge build.
- The local installer ZIP is an acceptance build, not a published release artifact.

## 8. Sign-off

Corvus 1.6.0 is verified as a published GitHub release with a green main CI run, a successful release workflow, bilingual release documentation, independently verified Linux, Windows and combined assets, and formal QA acceptance on the frozen source tree. This verification does not certify a live service, a 72-hour soak, or an operational container platform.
