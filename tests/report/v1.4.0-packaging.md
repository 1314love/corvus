## Safety note and limitations

- Safety containment incident: the first browser-harness launch patched only `background.js`; the offscreen shared chunk still defaulted to 7330. The test extension therefore registered with the live 1.0.0 daemon and its auto probe found the user's Edge on 9222; the test daemon briefly attached browser-level CDP to that endpoint. No MCP/REST tool call or page navigation was sent over that link. The test service was stopped immediately, every JavaScript file in the test extension copy was then patched to 17354, and the extension CDP setting was pinned to closed 9666 before the recorded run. The final 72-check run used only 17354/17355, 9555 and 17400. Live Corvus was not sent any request; only `Get-Service Corvus` status was checked (Running, 1.0.0 baseline unchanged).
- The Linux `.tar.gz` was not built on this Windows host; `scripts/package-linux.sh` requires Linux x86_64. Linux packaging remains for CI or a Linux builder.
- This is a Windows packaging/installer acceptance. Docker image and Kubernetes checks were not rerun here.
- Evidence was collected from the current frozen worktree; no commit, tag, push or release was made.
