## Safety note and limitations

- The first browser harness used the default CDP sentinel incorrectly: the test extension briefly auto-detected the user's Edge on 9222 and the test daemon attached browser-level CDP to it. No MCP/REST tool call or page navigation was sent over that link. The test service was stopped immediately, the extension's stored CDP endpoint was set to closed port 9666, the default sentinel was restored, and the final 80-check browser suite used only 17364/17365, 9555 and 17400. This was a harness-containment mistake, not a product behavior.
- At final cleanup no service named `Corvus` existed and ports 7330/7331 were not listening. This task did not target that service; only the `CorvusV150Test` service was created and removed.
- Linux archives were not built on this Windows host; `scripts/package-linux.sh` requires Linux x86_64.
- Evidence is from the frozen worktree; no commit, tag, push or release was made.
