## Installer acceptance

The extracted package was under `%TEMP%\Corvus v160 Zip Pkg`. A HomeDir directly under `%TEMP%` was rejected because `install-windows.ps1:83` derives `repoRoot` from the package parent and the guard at `install-windows.ps1:115-116` refuses a HomeDir inside that root. The throwaway HomeDir was therefore placed outside the repository and temp:

    C:\CorvusV160Test Home

Install command:

    & 'C:\Users\Administrator\AppData\Local\Temp\Corvus v160 Zip Pkg\install-windows.ps1' \
      -ServiceName CorvusV160Test -HomeDir 'C:\CorvusV160Test Home' \
      -WsPort 17374 -HttpPort 17375

No `-DistDir` was passed; the installer used the binaries beside itself.

## Limitations and residual risks

- The ZIP is a local acceptance artifact, not a CI rebuild. It was built from a dirty worktree at HEAD `61ca85fbf5af3e4acd830ef4b8254272f3fed0a8`; the v1.6 changes were uncommitted. No commit was made.
- QA results quoted above are task-125 evidence, not a second QA run. This task exercised packaging, install, MCP/REST, browser and guardrail behavior only.
- `install-windows.ps1` rejects a HomeDir under the package parent when the package is extracted under `%TEMP%`; the acceptance therefore used `C:\CorvusV160Test Home`. This is a guard, not a failure, but operators should extract outside temp or choose a HomeDir outside the derived repository root.
- `uninstall-windows.ps1` defaults HomeDir to `%ProgramData%\Corvus`. `-PurgeData` removes the configured HomeDir only when `-HomeDir` matches; otherwise the custom home remains. The correct purge invocation is shown above.
- Guardrails are policy checks, not a network sandbox. CDP was explicitly pinned to the dedicated 9555 endpoint; the extension-only channel cannot serve `browser_cookies`, which returned `CAPABILITY_UNAVAILABLE`. Cookie redaction was verified over CDP.
- Browser coverage is Edge 157.0.4341.46 only. Firefox remains unsupported; no Chrome or macOS/Linux browser run was part of this task.
- Linux/macOS archives were not built on this Windows host. NFR-3 soak certification and CI release identity are outside this acceptance.
- The local test service, custom HomeDir, fixture process and browser profile were removed; no test service or test listener remains.
