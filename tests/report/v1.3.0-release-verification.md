## Known limitations

- NFR-3 is not passed. The 72-hour soak was stopped at the client's request
  after about eight hours; 1.3.0 is not soak certified.
- Firefox remains unsupported (NFR-6 deviation).
- CDP is loopback-only and unauthenticated. Docker and Kubernetes deployments
  cannot reach host browser loopback and are not hosted deployments.
- Forced `cdp` has no extension fallback. macOS has no installer; Linux
  packaging is x86_64 only.
- Extension `@eN` and CDP `@c<backendNodeId>` references are separate
  namespaces; full bridging is deferred.
- One historical pre-freeze read-only `GET /json/version` to Edge on 9222 was
  disclosed; the final matrix used isolated headless browsers.
- No live 1.3.0 deployment is claimed. The development machine continued to run
  the existing 1.0.0 service with the user's normal Edge.
