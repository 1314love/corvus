## Browser checks

The page under test was served by a temporary Node HTTP server on 127.0.0.1:17400. It contained a heading, a Click button whose handler changes the output text, and a named Name input.

The extension under test was a temporary copy of the packaged extension. Only daemon_url.js was changed, replacing the default ws://127.0.0.1:7330 with ws://127.0.0.1:17344 so the test copy could not contact the live daemon. The rest of the extension code, including the 1.3.0 manifest, is byte-identical to the package.

## Idempotent install and purge

The base installer was rerun against the same service and HomeDir. It exited successfully, the service remained Running, /health stayed 1.3.0 with channel auto, the base AppParameters were restored, the extension reconnected, and tools/list still returned 43.

Uninstall-windows.ps1 -PurgeData then exited successfully. The CorvusV130Test service was gone, the whole HomeDir was removed, and ports 17344/17345 no longer listened. The extracted package, temporary extension copy, Edge profile and web root were removed. Ports 9555 and 17400 no longer listened.

The live Corvus service was never stopped or reconfigured by this task. It remained Running with ImagePath C:\Users\Administrator\.corvus\bin\nssm.exe, and the harness observed process id 3684 at completion. A later status check at 12:51 observed process id 16208, so the live service was restarted externally after acceptance; ImagePath was unchanged. No live port 7330/7331 was called by this task.
