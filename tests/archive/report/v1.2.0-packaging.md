## Defects and observations

- No product defect was found. scripts/package.sh, scripts/install-windows.ps1 and scripts/uninstall-windows.ps1 did not need changes.
- On the first install, nssm start printed exit code 1 while Windows reported SERVICE_START_PENDING. The installer's wait loop observed Running and the health check passed. On the idempotent rerun nssm start succeeded. This is the installer's documented tolerance path, not an acceptance failure.
- The first harness run failed on its own expected-path string because %TEMP% resolved to the 8.3 form C:\Users\ADMINI~1\... while the service stored the long path. The harness now normalizes HomeDir with [System.IO.Path]::GetFullPath before comparing. This was a test harness issue, not installer behavior.
