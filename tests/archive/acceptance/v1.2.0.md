### D2: tab-id namespaces are not interchangeable

Extension tab ids are decimal strings; CDP target ids are 32-hex strings. v1.2.0 does not bridge the two namespaces, and the Lead deferred full bridging to v1.3. The accepted behaviour is:

- A numeric extension tab id passed to a CDP-capable tool returns `BAD_ARGS: omit tab_id to use the active tab; extension tab ids are not CDP target ids` with a `hint` and the original `tab_id`.
- A 32-hex CDP target id passed to an extension-only tool returns `BAD_ARGS: omit tab_id to use the active tab; CDP target ids are not extension tab ids`.
- The CDP-only tools `browser_console`, `browser_cookies`, `browser_dialog` and `browser_emulate` also apply the guard when given a numeric extension tab id; they do not return `INTERNAL`.
- The active-tab workaround works: `page_snapshot` with no `tab_id` succeeds.
- D2 probe result: 13/13 checks PASS.

Evidence: `.../evidence/final-auto/d2.json` and `.../evidence/final-explicit/switch.json`.
