# Archived test material / 已归档的测试材料

[English](#english) | [中文](#中文)

## English

Everything in this folder predates 1.4.0 and was superseded. It is kept for audit only. The M1 to M4 playbooks describe the JavaScript extension and 18 to 26 tools; the 0.1.0 to 1.3.0 validation and release records are correct only for their release. Paths mentioned inside these files refer to their pre-archive location under `tests/acceptance` and `tests/report`.

- `acceptance/`: the M1 to M4 and M4-perf playbooks, the 0.1.0 Brave and Chrome validation matrices, and the 1.1.0 to 1.3.0 acceptance records.
- `report/`: the M1 to M4 report templates, the 26-tool live report, and the 0.1.0 to 1.3.0 release verification and packaging records.

Current verification lives in [../acceptance/v1.6.0.md](../acceptance/v1.6.0.md), the draft [../acceptance/v1.7.0.md](../acceptance/v1.7.0.md), `tests/conformance/run.sh`, `tests/perf/` and `tests/report/v1.6.0-*`; older reports stay as history.

## 中文

本目录内容均早于 1.4.0，已被取代，只作审计追溯。M1 至 M4 手册描述 JavaScript 扩展与 18 至 26 个工具的旧表面；0.1.0 至 1.3.0 的验证与发布记录只对其所属版本成立。文件内提到的路径指其归档前在 `tests/acceptance` 与 `tests/report` 下的位置。

- `acceptance/`：M1 至 M4 及 M4-perf 验收手册、0.1.0 的 Brave 与 Chrome 验证矩阵，以及 1.1.0 至 1.3.0 的验收记录。
- `report/`：M1 至 M4 报告模板、26 工具时期的实测报告，以及 0.1.0 至 1.3.0 的发布验证与打包记录。

当前验证见 [../acceptance/v1.6.0.md](../acceptance/v1.6.0.md)、草案 [../acceptance/v1.7.0.md](../acceptance/v1.7.0.md)、`tests/conformance/run.sh`、`tests/perf/` 与 `tests/report/v1.6.0-*`；更早的报告仅作历史。
