# Corvus 0.1.0

Released 2026-11-14.

Corvus is a local Rust daemon plus a Manifest V3 browser extension. It exposes the browser that the user already runs to MCP clients over stdio or streamable HTTP.

## What ships

- A 32-tool MCP server covering navigation, perception, input, tabs, network capture and interception, downloads, uploads, sessions, metrics and logs.
- A Manifest V3 extension; release validation used Edge.
- Per-tab scheduling where calls on one tab are ordered and calls on different tabs run in parallel, plus MCP request cancellation.
- Session recording, inspection, replay and JSONL export.
- `GET /health`, Prometheus text at `GET /metrics`, and the `metrics` and `logs_tail` tools.
- Windows install and uninstall scripts, a release bundle with `SHA256SUMS`, and a client configuration generator for stdio and HTTP clients.

## Install in three steps

1. Build the release bundle from the repository root in MSYS bash or Git Bash:

```bash
bash scripts/package.sh
```

2. Install the Windows service from an elevated PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1
```

3. Open `chrome://extensions` or `edge://extensions`, enable Developer mode, choose Load unpacked, and select `%USERPROFILE%\.corvus\extension`.

The full procedure, including custom paths, upgrade, uninstall and troubleshooting, is in [docs/04-install.md](../04-install.md).

## Client configuration

Generate the MCP client entry with the installed binary:

```powershell
& "$env:USERPROFILE\.corvus\bin\corvus.exe" config --transport http
```

Paste the printed `mcpServers` object into the client. `--client` accepts `claude`, `cursor`, `dsh`, `cline` or `generic`. For a stdio-only client, stop the service first and generate with `--transport stdio`; the service and the stdio bridge cannot share the default ports.

## Verify

```powershell
Invoke-RestMethod http://127.0.0.1:7331/health
(Invoke-WebRequest http://127.0.0.1:7331/metrics).Content
```

`/health` reports `status: ok`, the version and the recording database path. `/metrics` returns Prometheus text. An MCP `tools/list` request returns all 32 tools.

## Known limitations

- The 72-hour soak has not yet been run.
- Chrome for Testing 157.0.8103.78 passed 101 checks: smoke 7/7, M3 34/34, M4 cancellation 16/16, M2b 44/44. See the [Chrome validation matrix](../../tests/acceptance/Chrome-validation.md).
- Firefox is not supported yet: the extension relies on Chromium MV3, `chrome.offscreen` and `chrome.debugger`; a separate port of the extension would be needed, and the NFR-6 deviation is pending a client decision. See the [Firefox feasibility assessment](../06-firefox-assessment.md).
- In headless Chrome, a synthetic click on an `<a download>` link does not start a download; navigate to the attachment URL instead, after which `download_wait` and `download_list` report `complete`.
- The installer is Windows-only.
- `CANCELLED` is not retryable.
