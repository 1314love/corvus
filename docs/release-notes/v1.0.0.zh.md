# Corvus 1.0.0

发布于 2026-11-14。

Corvus 是本地 Rust 守护进程加 Manifest V3 浏览器扩展，通过 stdio 或 streamable HTTP 把用户已有的浏览器提供给 MCP 客户端。

## 本版本包含

- 32 个工具的 MCP 服务端，覆盖导航、感知、输入、标签、网络捕获与拦截、下载、上传、会话、指标与日志。
- Manifest V3 扩展；发布验证覆盖 Edge、Chrome for Testing 157.0.8103.78 与 Brave Browser 157.1.99.57。
- 按标签调度：同一标签内的调用按顺序执行，不同标签的调用并行执行；同时支持 MCP 请求取消。
- 会话录制、查看、回放与 JSONL 导出。
- `GET /health`、`GET /metrics` 的 Prometheus 文本，以及 `metrics` 与 `logs_tail` 工具。
- Windows 安装与卸载脚本、带 `SHA256SUMS` 的发布包，以及支持 stdio 与 HTTP 的客户端配置生成器。

## 三步安装

1. 在 MSYS bash 或 Git Bash 中，从仓库根目录构建发布包：

```bash
bash scripts/package.sh
```

2. 在管理员 PowerShell 中安装 Windows 服务：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1
```

3. 打开 `chrome://extensions`、`edge://extensions` 或 `brave://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，目录选 `%USERPROFILE%\.corvus\extension`。

完整步骤（自定义路径、升级、卸载与故障排查）见 [docs/04-install.zh.md](../04-install.zh.md)。

## 支持的浏览器

Edge、Chrome 与 Brave（Chromium 120+）。暂不支持 Firefox 121+；NFR-6 偏差仍未关闭，建议采用方案 A。参见 [Firefox 可行性评估](../06-firefox-assessment.zh.md)。

## 客户端配置

用已安装的二进制生成 MCP 客户端条目：

```powershell
& "$env:USERPROFILE\.corvus\bin\corvus.exe" config --transport http
```

把输出的 `mcpServers` 对象粘贴到客户端。`--client` 接受 `claude`、`cursor`、`dsh`、`cline` 或 `generic`。仅支持 stdio 的客户端需先停止服务，再用 `--transport stdio` 生成；服务与 stdio 桥不能共用默认端口。

## 验证

```powershell
Invoke-RestMethod http://127.0.0.1:7331/health
(Invoke-WebRequest http://127.0.0.1:7331/metrics).Content
```

`/health` 返回 `status: ok`、版本号与会话数据库路径。`/metrics` 返回 Prometheus 文本。MCP 的 `tools/list` 请求返回全部 32 个工具。

## 已知限制

- 干净的 NFR-3 72 小时浸泡测试于 2026-11-14T14:41:37Z 启动，将于 2026-11-17T14:41:37Z 完成；在完成前，72 小时结论仍为待定。
- 暂不支持 Firefox 121+。NFR-6 偏差仍未关闭；建议采用方案 A（将 Firefox 保持在支持矩阵之外）。参见 [Firefox 可行性评估](../06-firefox-assessment.zh.md)。
- 安装器仅支持 Windows。
- 在 headless Chrome 与 Brave 中，对 `<a download>` 链接的合成点击不会启动下载；改为导航到附件 URL，之后 `download_wait` 与 `download_list` 会报告 `complete`。

## 从 0.1.0 升级

用相同路径运行同一个安装命令。安装器会停止服务、替换二进制与扩展，然后重新启动服务；SQLite 数据库会保留。若扩展文件有变化，重新加载扩展，然后运行 `corvus.exe doctor` 并检查报告的版本。参见[安装指南中的升级步骤](../04-install.zh.md)。
