## 工作树内容

工作树声明十类 62 个 MCP 工具并新增 18 个工具；page 类别从 11 个增至 15 个。它不新增 crate 或 REST 路由，录制 schema 保持不变，但扩展权限随 `tabGroups` 从 10 项增至 11 项。每个截图与 PDF 都由共享守护进程派发路径只最终处理一次，二者都不在会话步骤中内联存储。

## 新增工具

- **Page：** `page_pdf`、`page_links`、`page_forms` 与 `page_accessibility`；page 现在有 15 个工具。
- **Input：** `browser_drag`、`browser_focus` 与 `browser_highlight`；input 现在有 10 个工具。
- **Tabs：** `tab_group`、`tab_duplicate`、`window_list` 与 `window_new`；tabs 现在有 8 个工具。
- **Storage：** `cookie_set`、`cookie_clear`、`storage_get`、`storage_set` 与 `storage_clear`；这是新的五工具类别。
- **Diagnostics：** `health` 与 `version`；diagnostics 现在有 6 个工具，二者均为守护进程本地。

## browser_screenshot 输入

| 输入 | 含义 |
| --- | --- |
| `target` | `viewport`（默认）、`full_page` 或 `element` |
| `ref` | CDP 上为 `@c<backendNodeId>`，扩展上为 `@e<number>`；`element` 必填，错误类型返回 `BAD_ARGS` |
| `format` | `webp`（默认）、`png` 或 `jpeg` |
| `quality` | 1..100，默认 80；png 忽略 |
| `inline` | 默认 false；true 追加一个 MCP 图像内容块 |
| `tab_id` | 可选标签选择器；省略时使用活动标签页 |

## 捕获目标与格式

`viewport` 使用 `Page.captureScreenshot`，不捕获视口之外。`full_page` 从布局尺寸读取 CSS 内容尺寸并捕获整个可滚动页面。`element` 把引用解析为包围盒并捕获该区域；只有元素捕获返回 `bbox`。扩展使用现有调试通道，只有活动标签页的 PNG 视口才可回退到 `chrome.tabs.captureVisibleTab`。

`format` 选择编码器与 `mime_type`。`quality` 发送给 webp 与 jpeg，png 省略。元素引用按通道区分：CDP 接受来自 `page_snapshot` 的 `@cN`，扩展接受 `@eN`；传入另一种类型会在捕获前返回 `BAD_ARGS`。

## page_pdf 契约

`page_pdf` 打印所选或活动标签页，`paper_width` 默认 8.5 英寸、`paper_height` 默认 11、`landscape` 默认 false、`print_background` 默认 true、`scale` 取 0.1 到 2，页边距固定 0.4 英寸。守护进程解码 PDF，执行 32 MiB（33,554,432 字节）解码上限，并在 `<daemon home>/pdf` 下以 create-new 语义写入唯一的 `page-<unix_millis>-<uuid8>.pdf`。

结果携带 `format: "pdf"`、`mime_type: "application/pdf"`、`tab_id`、`url`、`path`、`bytes`、`sha256`、纸张字段与 `summary`；没有 base64 字段。`page_pdf` 被排除在 `browser_batch` 之外，重放以 `page_pdf_not_replayable` 跳过它。

## 截图存储与信封

守护进程把解码后的图像限制在 8 MiB，解码前拒绝明显超大的编码载荷，校验解码尺寸，并在 `<home>/screenshots/` 下写入 `screenshot-<unix-millis>-<uuid8>.<ext>`，不覆盖已有文件。结果返回 `width`、`height`、`bytes`、`sha256`、`path`、`summary` 与 `inline`，不再返回 base64。

普通截图结果是一个紧凑 JSON 文本块。`inline: true` 时，MCP 信封追加第二个图像内容块并省略 `structuredContent`。`browser_batch` 以 `BAD_ARGS` 拒绝 `inline: true`；`inline: false` 的步骤会保存文件，并经共享派发路径只最终处理一次。录制会剥离截图与 PDF 的 `data` 与 `image.data`，重放以 `screenshot_not_replayable` 跳过截图。

## 通道与扩展

CDP 提供 46 个浏览器类工具，扩展提供 42 个，12 个为守护进程本地。四个标签页与窗口工具（`tab_group`、`tab_duplicate`、`window_list`、`window_new`）仅扩展可用，强制 CDP 返回 `CAPABILITY_UNAVAILABLE`。扩展声明 11 项权限（含 `tabGroups`）、运行 42 个基于 debugger 的处理器并保持 `all_frames: false`；`health` 与 `version` 仅守护进程本地。

`auto` 下已连接时优先 CDP，仅在 Unsupported 路由下使用扩展。`@cN` 引用仅限 CDP，`@eN` 引用仅限扩展；错误类型返回 `BAD_ARGS`。守护进程像记录其他调用一样记录新工具，录制 schema 及其脱敏规则保持同一 schema 版本。

## 工具面

1.7.0 工作树有十类 62 个工具：page 15、input 10、tabs 8、network 5、storage 5、files 3、cdp 5、sessions 4、diagnostics 6 与 help 1。CDP 提供 46 个，扩展提供 42 个，12 个为守护进程本地；38 个双通道可用，8 个仅 CDP，4 个仅扩展。已发布的 1.6.0 仍为九类 43 个工具；没有删除工具，也没有改变既有输入。

## 架构

`crates/corvus-mcp/src/tools.rs` 声明十类 62 个规格；`crates/corvus-application/src/spec.rs` 从 33 个增至 49 个浏览器侧规格；`crates/corvus-cdp/src/tools.rs` 列出 46 个 CDP 浏览器类工具。守护进程新增 `page_pdf`、`page_links`、`page_forms`、`page_accessibility`、`browser_drag`、`browser_focus`、`browser_highlight`、四个标签页/窗口工具、五个存储工具与 `health`/`version` 派发。

十个 crate 不变。不新增 crate，也不改变 REST 路由。`finalize_screenshot_result` 与 `finalize_page_pdf_result` 从共享派发路径运行，因此顶层调用、扩展调用与 `browser_batch` 步骤都只最终处理一次。

## 守护策略与脱敏

`browser_screenshot`、`page_pdf`、`page_links`、`page_forms`、`page_accessibility`、`window_list`、`storage_get`、`browser_highlight`、`health` 与 `version` 对守护策略是只读的。`cookie_set`、`cookie_clear`、`storage_set`、`storage_clear`、`browser_drag`、`browser_focus`、`tab_group`、`tab_duplicate` 与 `window_new` 不是只读的。

录制会脱敏 `cookie_set.value` 与每个 `storage_set` 条目的值；守护策略把每个 `storage_get` 条目值替换为 `[redacted]` 并添加 `redacted: true`。截图像素与 PDF 字节不被检查、脱敏或包裹边界，需用 `deny_tools` 阻止。`browser_batch` 按名称排除十个工具，留下 42 个可批量工具；`storage`、`sessions` 与 `help` 不在可批量类别内。
