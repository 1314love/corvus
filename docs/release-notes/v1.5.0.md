## What is in the release

The 1.5.0 release adds browser-perception and diff capabilities to `page_snapshot` and internationalizes the extension UI. It adds no MCP tool: the catalogue stays at 43 tools in nine categories.

## Snapshot perception v2

`page_snapshot` now traverses open shadow roots and same-origin child frames. The top document has an empty frame path; child frames follow document order as `f0`, `f0.0`, `f1` and so on. Compact lines inside a child frame append `frame="<path>"`, and JSON nodes carry `frame` only when it is non-empty. A page with child frames adds `frames: {total, included, skipped: [{frame, url, reason}]}`; `reason` is `cross_origin`, `unavailable` or `geometry_unavailable`, and a cross-origin frame is skipped rather than silently dropped. `max_nodes` is one budget across every included document, `include_bbox` boxes are relative to the top viewport, and `viewport_only` and `include_bbox` are otherwise unchanged.

## Compact diffs

`diff` is a boolean input, default false. It is valid only for compact output; `format: "json"` with `diff` returns typed `BAD_ARGS`. The daemon application layer computes the diff once from a 64-entry LRU keyed by browser, session and tab, so the extension, direct CDP and `browser_batch` paths share one grammar. A compact request with `diff: false` refreshes the baseline; a diff request never refreshes it, and JSON does not touch it. With a baseline for the same URL, the result adds `diff: {baseline: true, unchanged, changed, added, removed}` and marks current lines with two spaces (unchanged), `+ ` (added) or `~ ` (changed); removed baseline lines are appended in old order with `- `. Without a baseline, or after a URL change, it reports `{baseline: false, 0, 0, 0, 0}` and leaves the text unmarked. See [09-tools.md](../09-tools.md).

## Extension i18n

The Vue UI uses vue-i18n 11.4.20 with 64-key English and Simplified Chinese catalogs under `extension/src/ui/shared/i18n/`. Locale detection reads `chrome.i18n.getUILanguage()` and `navigator.language`: `zh*` selects `zh-CN`, everything else selects English. An explicit choice is persisted under `corvus.locale`, switching is reactive without a reload, and `document.documentElement.lang` follows the active locale. The MV3 manifest declares `default_locale: en`; `_locales/en` and `_locales/zh_CN` mirror the catalogs for the extension name, description and action title. The build now emits 14 files including both catalogs, with ten permissions, 25 handlers and `all_frames: false` unchanged.

## Tool surface

The MCP catalogue is unchanged from 1.4.0: 43 tools in nine categories, the compact single JSON text block per successful `tools/call`, no `structuredContent`, and `browser_batch` limited to 20 allowlisted steps. Channel availability is unchanged: 25 browser-facing tools on the extension channel and 33 on forced CDP.

## Architecture

The ten crates are unchanged: `corvus-domain`, `corvus-application`, `corvus-api`, `corvus-proto`, `corvus-mcp`, `corvus-transport`, `corvus-record`, `corvus-cdp`, `corvusd` and `corvus`. `crates/corvus-application/src/snapshot_diff.rs` owns the baseline cache, and `Router::finish_page_snapshot` in `crates/corvus-application/src/router.rs:483` applies it once for the extension path, the direct CDP path in `crates/corvusd/src/lib.rs` and each `browser_batch` step. `crates/corvus-cdp/src/tools.rs` walks the frame tree; `extension/src/content/runtime.ts` performs the same traversal on the extension channel. There is no new crate and no recording schema change.

## Known limits

- NFR-3 is still unpassed; the 72-hour soak stopped after about eight hours.
- No live 1.5.0 deployment is claimed, and no Docker registry publication or Kubernetes runtime evidence is claimed for this release.
- QA and installer acceptance were measured on the frozen source tree at HEAD 73092ea before the release commit; the local installer ZIP is distinct from the published CI rebuilds. The release is published from tag `v1.5.0`.
- Snapshot diffs are compact-only; `format: "json"` with `diff` is typed `BAD_ARGS`.
- Cross-origin frames are skipped and never read, so their content cannot appear in a snapshot.
- During packaging acceptance the first harness invocation briefly attached browser-level CDP to the normal Edge on port 9222. No MCP or REST tool call or page navigation was sent over that link; the test service was stopped, the test endpoint was pinned to closed port 9666, and the recorded browser suite used only isolated ports 17364/17365, 9555 and 17400.

No recording schema change is part of this release; schema version remains 1. The Cargo workspace, extension package, manifest and build check are aligned at 1.5.0, including the metadata fix in 7d0e7c7. The release is published from tag `v1.5.0`; check it out or install the published assets.
