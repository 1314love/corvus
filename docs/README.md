## 中文

每份文档都有英文与中文两个版本，同一目录、同一提交。文件名规则：英文版 `<name>.md`，中文版 `<name>.zh.md`，
两版首行互相链接。缺一版视为未完成：要么两版一起交，要么把缺口登记到本表状态列标 `pending`，并在下一个
里程碑评审前补齐。当前全部文档均已成对。

维护要求见 [LANGUAGE.md](LANGUAGE.md) 与 [../CONTRIBUTING.md](../CONTRIBUTING.md) 第 4 节。
